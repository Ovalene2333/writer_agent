# 修订生成感

以审阅证据为边界，不对全文进行同义改写。先判断问题来自句法重复、信息功能重复，还是叙述者替人物和读者总结。

## 操作

1. 读取命中原文及足以判断因果和指代的相邻上下文。
2. 标出必须保留的事实、动作结果、人物选择、声线和节奏重音。
3. 删除重复功能，恢复必要的施事、对象或因果承接。
4. 调整句子长度只服务于信息和节奏，不追求长短交替的统计外观。
5. 精确数字、技术语言和短句若直接影响判断、风险或行动，应保留。
6. 修订完成后复读完整段落，确认没有为了自然感稀释事实或新增心理解释。

需要判断常见边界时读取 `references/boundaries.md`。
