# 修复作者政策命中

1. 以问题中的 `policyId`、`policyVersion`、证据和修订目标为准；版本不一致时先读取当前政策，不猜测旧要求。
2. 若问题提供 `skillId`，加载对应 Skill；仅在其主说明不足时读取声明资源。
3. 检查证据是否满足政策的证据要求，并逐项核对放行条件。符合任一放行条件时不要为了过门禁而改写。
4. 只修改能消除该命中的最小连续范围，保留事实、人物目标、获知路径、线索顺序和有效节奏。
5. 修订后重新提交，让运行时复验。不得把删除问题规则、停用政策或改写无关正文当作修复。

政策属于试运行或提醒级别时，Agent 可以保留有明确叙事理由的原文，但必须说明所依据的放行条件。硬门禁仍须以证据为基础，不能因政策措辞宽泛而扩大修改范围。
